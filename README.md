# НАУЧДВИЖ

Адаптивный фронтенд для поиска научных конференций по макету «Конференции» в Figma. Один и тот же интерфейс работает с демонстрационными данными или с HTTP API. По умолчанию включён демонстрационный режим.

## Быстрый старт

Требуется Node.js 22 или новее в PATH и современный браузер. Сторонних пакетов и шага сборки нет. В терминале из корня проекта выполните:

```sh
node server.mjs
```

Откройте [localhost:5173](http://localhost:5173). Чтобы остановить сервер, нажмите Ctrl+C в его терминале. Если установлен npm, эквивалентная команда — `npm start`. Для другого порта задайте переменную окружения `PORT` перед запуском. Сервер слушает только адрес обратной связи.

В Windows можно дважды нажать `Запустить.cmd`. Для работы в Visual Studio Code откройте `НАУЧДВИЖ.code-workspace`. В доверенной рабочей области доступны задачи запуска и тестирования. F5 запускает сервер и открывает Edge. В Windows приоритет имеет Node.js из PATH. Локальный скрипт также поддерживает NODE_HOME и установленную среду Node.js редактора Codex.

## Стек и возможности

| Часть | Реализация |
| --- | --- |
| Интерфейс | HTML5, CSS Grid и Flexbox, JavaScript ES-модули, DOM API. Навигация по hash, нативные диалоги, закреплённая шапка. Шрифты Inter, иллюстрации и иконки поставляются с проектом. |
| Каталог | Главная и отдельная страница конференций. Поиск по названию, направлению и индексам, фильтры, сортировка по сроку подачи, страницы по 6 карточек. Окно подробностей показывает описание и ссылку организатора, если они предоставлены. |
| Избранное | Звезда в карточке и окне подробностей, отдельная страница сохранённых конференций и её пустое состояние. |
| Личный кабинет | Редактирование профиля и резюме, локальный импорт PDF/DOCX/TXT и скачивание оригинала, отдельный экспорт полей профиля в UTF-8 TXT, достижения, интересы, команды и конференции, в которых пользователь участвует. Вкладка прошедших пока показывает пустое состояние. |
| Данные | 16 демонстрационных конференций из макета. Профиль и избранное сохраняются в localStorage в деморежиме. Для серверного режима реализован адаптер на Fetch API. |
| Разработка | Локальный HTTP-сервер на встроенных модулях Node.js, тесты на `node:test` и `node:assert/strict`. |

«Команды», «Антиплагиат», «Автооформление» и «Сборник» открывают согласованный экран «В разработке». Вход в аккаунт, база данных, серверное хранение файлов и регистрация на конференцию внутри сайта в поставку не входят. Кнопка участия открывает сайт организатора. Даты из макета демонстрационные.

## Где менять код

| Путь | Ответственность |
| --- | --- |
| `public/index.html`, `public/assets/`, `public/assets/fonts/inter.css` | HTML-оболочка, настройка источника данных, локальные ресурсы и лицензия шрифта. |
| `src/app.js` | Запуск приложения, маршрутизация и связь разделов с общим интерфейсом. |
| `src/features/` | Поведение каталога, профиля и избранного: обработка действий, формы, загрузка и сохранение. |
| `src/views/` | Разметка каталога, карточки, избранного, подробностей, профиля, шапки и подвала. Функции получают данные аргументами. |
| `src/domain/conference-filters.js` | Фильтрация и сортировка без доступа к браузеру или сети. |
| `src/services/frontend-repository.js`, `local-storage.js` | Получение каталога, чтение и изменение профиля и избранного. Здесь меняется контракт транспорта. |
| `src/services/request-error.js`, `resume-file-store.js` | Сообщения об ошибках HTTP и локальное хранение оригинальных файлов резюме в IndexedDB. |
| `src/fixtures/` | Примеры полных записей и исходный профиль. Подгружаются в деморежиме. |
| `src/ui/`, `src/styles/`, `src/shared/` | Адаптивное поведение, таблица стилей, экранирование текста и общие функции разметки. |
| `tests/` | Проверки фильтров, формата дат, контракта HTTP, обработки ошибок, пагинации и отображения внешних данных. |

В `public/assets/` ресурсы разложены по назначению: `fonts/` содержит начертания Inter с лицензией, `icons/` — иконки и аватарки, `illustrations/` — изображения баннеров, `decorations/` — разделители и графику подвала. Например, `inter-regular.ttf` соответствует насыщенности 400, а `inter-bold.ttf` — 700. Соответствия указаны в `inter.css`.

## Подключение бэкенда

1. Раздайте содержимое `public/` из корня сайта, а каталог `src/` по пути `/src/` с MIME-типами JavaScript и CSS. Пути к ресурсам абсолютные от корня. Перезапись адресов для hash-маршрутов не нужна.
2. Реализуйте перечисленные ниже маршруты на том же origin или направьте `/api/` к бэкенду через reverse proxy. Встроенный `server.mjs` раздаёт только статические файлы.
3. В `public/index.html` укажите `<meta name="api-base" content="/api">` и обновите страницу. Пустое значение включает деморежим. Запросы отправляют cookie текущего origin. Идентификация пользователя, проверка прав и валидация изменений выполняются сервером.
4. Для проверки откройте каталог, сохраните конференцию, перезагрузите страницу избранного, измените город в профиле и снова перезагрузите страницу. Оба изменения должны вернуться из API.

### Контракт, который использует клиент

Все пути ниже указаны относительно `api-base`. JSON передаётся без обёрток `data` или `results`. Каталог загружается независимо через GET /conferences. После отображения каталога клиент проверяет сессию через GET /me. Ответ 401 включает гостевой режим, запрос избранного выполняется только после успешного получения профиля. Ошибки аккаунта не блокируют каталог. После входа приложение авторизации должно вызвать window.dispatchEvent(new Event("auth-changed")); также доступна кнопка «Обновить данные аккаунта». Экран входа предоставляет бэкенд или отдельный модуль авторизации. Поиск и пагинация выполняются в браузере, поэтому каталог возвращается целиком.

| Метод и путь | Запрос | Успешный ответ |
| --- | --- | --- |
| `GET /conferences` | — | 200, массив конференций или `[]`. |
| `GET /me` | Cookie сессии | 200, объект текущего профиля. |
| `PATCH /me` | JSON с редактируемыми полями формы, например `{"city":"Тюмень"}`. Отсутствующие поля сохраняются. | 200, полный профиль после обновления. |
| `GET /me/favorites` | — | 200, массив строковых ID, например `["conf-1"]`. |
| `PUT /me/favorites/{id}` | Без тела | 204, конференция в избранном. Повторный запрос даёт тот же результат. |
| `DELETE /me/favorites/{id}` | Без тела | 204, конференция удалена из избранного. Повторное удаление допустимо. |

У конференции обязательны строки `id`, `title`, `category`, `cost`, `format`, `deadline` и массив строк `indexes`. ID уникален и стабилен. Формат срока подачи — `ДД.ММ.ГГГГ`. Поле `excerpt` задаёт краткое описание. Необязательный массив `description` содержит абзацы вида `{"text":"Текст","url":"https://example.org","label":"Подробнее"}`, где ссылка и её подпись необязательны. Для кнопки участия предусмотрено поле `participationUrl`. Полный пример — [данные конференций](src/fixtures/demo-conferences.js).

Профиль содержит строки `id`, `name`, `degree`, `email`, `phone`, `telegram`, `age`, `city`, `bio`, `education`, `specialty`, `job`, `interests` и массив строк `participatingIds`. Возраст передаётся строкой, интересы разделяются запятыми. Необязательные массивы `achievements` и `teams` имеют элементы `{title, detail?}` и `{name, memberCount?}` соответственно. Полный пример — [профиль](src/fixtures/demo-profile.js). Поля ID, участия, команд и достижений управляются сервером.

При недоступности API или ошибке контракта загрузки пользователь видит экран повторной попытки. Клиент подтверждает изменение профиля и избранного только после успешной записи. В деморежиме сохраняются прежние ключи `nauchdvizh:profile` и `nauchdvizh:favorites`. Автоматический перенос локальных записей в серверную учётную запись не предусмотрен.

### Состояния запросов и экспорт

Ошибки 401, 403, 400/422, 429 и 5xx имеют отдельные сообщения. Для ошибок формы сервер может вернуть JSON вида `{"errors":{"email":"Некорректный адрес"}}`. Поля подсвечиваются, введённые значения сохраняются. Во время записи кнопки показывают занятость. Избранное блокируется отдельно по ID конференции.

В раскрытом блоке резюме кнопка «Экспортировать резюме (TXT)» выгружает сохранённые поля профиля в UTF-8. Кнопка «Импортировать резюме» сохраняет оригинальный PDF/DOCX/TXT в IndexedDB текущего браузера; скачивание возвращает исходный файл без преобразования. Для переноса файлов на сервер требуется отдельный файловый API.

Модули `src/features/catalog.js`, `profile.js`, `favorites.js` отвечают за поведение соответствующих разделов. `src/app.js` связывает их с маршрутизацией и общим интерфейсом.

## Проверка перед передачей

```sh
node --test
```

Команда запускается из корня, также доступна как `npm test`. Тесты HTTP-адаптера подставляют ответы сервера и проверяют пути, методы, JSON, ответы без тела и ошибки. Сквозную проверку авторизации и сохранения в базе нужно выполнить с развёрнутым бэкендом.

## Работа через GitHub

Репозиторий фронтенда: [MuiMawww/Frontend](https://github.com/MuiMawww/Frontend). Описание изменений находится в [CHANGELOG.md](CHANGELOG.md) и сообщениях коммитов. Для дальнейшей работы клонируйте этот репозиторий, создавайте отдельные ветки и отправляйте изменения через pull request.

В репозиторий передаются исходники, локальные ресурсы интерфейса и тесты. Деморежим работает сразу после клонирования. Проверки в GitHub Actions запускают тот же набор тестов на Node.js 22 и 24 при push и pull request. Для подключения API используйте раздел выше. Секреты и параметры серверной среды храните на бэкенде: браузер получает клиентский код целиком.

Лицензия шрифта Inter находится в [public/assets/fonts/inter-license.txt](public/assets/fonts/inter-license.txt).


### Импорт оригинального резюме

В блоке «Моё резюме» можно импортировать PDF, DOCX или TXT до 10 МБ. Оригинальный файл хранится в IndexedDB этого браузера с привязкой к ID профиля и скачивается без преобразования. Поля профиля не извлекаются из файла. Серверная загрузка ещё не подключена; для неё следует заменить адаптер `src/services/resume-file-store.js` после согласования API. Экспорт полей профиля в TXT остаётся отдельной функцией.

### Главный баннер и подвал

- Исходная иллюстрация робота хранится в `public/assets/illustrations/scientist-original.png` (2560×2560, без уменьшения и перекодирования). В `src/views/hero-illustration.js` SVG-маска отделяет неподвижный передний план от шестерёнок и лампы; координаты композиции заданы в системе 1600×1600. Робот выводится одним слоем, чтобы избежать двойных контуров.
- `src/views/gear-geometry.js` задаёт общий модуль зубьев, расстояния между осями и фазы четырёх шестерёнок. Соседние колёса вращаются в противоположных направлениях; скорость зависит от количества зубьев. Тесты проверяют синхронизацию и отсутствие пересечений зубьев в полном цикле зацепления.
- Лучи проявляются от центра лампы через SVG-область отсечения. Форма и цвет взяты из исходного изображения. При `prefers-reduced-motion: reduce` движение отключается, лучи остаются видимыми.
- `science-stripes-background.png` — исходный фон без круга, общий для баннера и подвала. Круг и плавные переходы добавлены в SVG/CSS.
- Общий подвал в `src/views/site-layout.js` подключён ко всем маршрутам; оформление и адаптивные сетки находятся в `src/styles/visual-refresh.css`. Контакты и партнёры показывают существующие информационные окна до заполнения настоящими данными.
